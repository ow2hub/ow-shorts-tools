OW Shorts Tools プライバシーポリシー

OW Shorts Tools は、YouTubeチャンネル「考えるダイヤ帯OW」の運営者が、自分のチャンネルに動画をアップロード・管理するためだけに使う個人用ツールです。一般公開はしていません。

取得する情報

Googleアカウントでの認可を通じて、YouTube Data API と YouTube Analytics API にアクセスします。使うのは、運営者自身のチャンネルの動画のアップロード、タイトルやサムネイルの設定、再生数などの統計の閲覧に限られます。

情報の扱い

認可トークンと取得したデータは、運営者のPCの中だけで保存・使用します。第三者への提供、販売、広告目的での利用は行いません。

アクセスの取り消し

Googleアカウントの「サードパーティ製のアプリとサービス」から、いつでもアクセスを取り消せます。

お問い合わせ

YouTubeチャンネル 考えるダイヤ帯OW までご連絡ください。
